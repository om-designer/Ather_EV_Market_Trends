# 🛵 Ather Electric Scooter Market Trends

## 📌 Project Overview
This project focuses on analyzing the electric scooter market with insights into sales performance, revenue, brand comparison, customer ratings, and sales channels. The goal is to transform raw data into meaningful insights using data analysis and interactive visualizations.

## 🎯 Objectives
- Analyze electric scooter sales and revenue performance.
- Compare brand-wise sales and performance.
- Identify top-performing brands.
- Analyze sales channel performance.
- Explore customer ratings and purchasing trends.
- Build an interactive dashboard for data-driven insights.

## 🛠️ Tools & Technologies
- **Excel** – Data handling and preparation
- **MySQL** – Database management and SQL analysis
- **Power BI** – Interactive dashboards and visualization

## 📊 Dashboard Highlights
- Key Performance Indicators (KPIs)
- Sales and revenue analysis
- Brand-wise performance comparison
- Sales channel analysis
- Customer rating insights
- Interactive filters and slicers

## 💡 Key Learnings
- Data cleaning and preparation
- SQL-based data analysis
- Data visualization and dashboard development
- KPI tracking and business analysis
- Extracting insights from datasets
